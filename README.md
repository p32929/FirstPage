# FirstPage

A simple browser homepage — set it as your new-tab page and get your own links instead of whatever the browser wants to show you. Built with React and Material-UI.

**Live:** https://p32929.github.io/FirstPage/

## Make it yours

1. Fork this repo and clone your fork
2. Edit your links in `src/Others/Globals.js`
3. Run it:

```bash
npm install
npm start
```

4. Deploy to GitHub Pages:

```bash
npm run predeploy
npm run deploy
```

5. Set the resulting URL as your browser's homepage / new-tab page

## Built with

* ReactJS (Create React App)
* Material UI
* Overmind for state
* React Router
* gh-pages for deployment
