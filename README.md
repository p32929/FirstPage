# FirstPage

A simple homepage for your browser with only your own links on it. Instead of the busy page your browser shows, you get a clean grid of the sites you actually use. Add a link once and it is there every time you open the page.

**Use it now:** https://p32929.github.io/FirstPage/

## Features

1. **Your own links** in a clean grid, one click away.
2. **Add a link** with the Add button: type a title and a web address.
3. **Remove links** with Delete mode.
4. **Saved in your browser:** your links are stored only on your own computer (in the browser's local storage). Nothing is sent anywhere, and no account is needed.

## Set it as your homepage

Open your browser's settings and set https://p32929.github.io/FirstPage/ as your homepage or startup page.

## Host your own copy

```bash
git clone https://github.com/p32929/FirstPage.git
cd FirstPage
npm install
npm start          # http://localhost:3000
```

To publish your copy on GitHub Pages, change `homepage` in `package.json` to your own address, then run `npm run deploy`.

## Built with

1. React (Create React App)
2. Material-UI
3. Overmind for state
4. gh-pages for publishing

> Looking for a new tab page instead? [Home](https://github.com/p32929/Home) is a newer browser extension that replaces the new tab page itself, with a clock, search and your links.
